# ── AI predictions: local Ollama ──────────────────────────────────────────────
#  No pip packages required.  Ollama handles everything externally.
#
#  SETUP:
#   1. Install Ollama: https://ollama.ai
#   2. Create a Modelfile for your GGUF:
#        FROM /full/path/to/Qwen2.5-7B-Instruct-Q6_K.gguf
#        PARAMETER num_gpu 33
#        PARAMETER num_ctx 3072
#        PARAMETER temperature 0.30
#        PARAMETER repeat_penalty 1.1
#   3. Register the model:
#        ollama create qwen2.5:7b -f Modelfile
#   4. Start Ollama:
#        ollama serve
#   5. Launch the app and click Refresh in the AI tab.
#
#  RTX 4060 8GB VRAM profile (Qwen2.5-7B-Q6_K ~5.9 GB):
#    num_gpu = 33        → all layers in VRAM
#    num_ctx = 3072      → comfortable KV cache (~0.8 GB remaining)
#    num_predict = 1200  → avoids runaway generation
